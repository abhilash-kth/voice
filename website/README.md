# SaaS Landing Page

Technical boilerplate only. Page content and visual design will be added after the product brief is complete.

## Stack

- Next.js 16.3.8 (App Router)
- React + TypeScript
- Tailwind CSS 4.3.3
- Framer Motion
- shadcn-compatible CSS variables and aliases

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
